Excel (recipients)
Required: an email column. Optional: name, organization, custom_message, or any other column. Use the same heading as {{ '{{column}}' }} in the subject or body.

Each person gets their own email. Example: write Dear {{ '{{first_name}}' }}, and Priya / Amit / Sara each see their own name. For a unique paragraph per person, add a custom_message column in Excel.

The app sends one message at a time and logs progress to send.log.

Before bulk sending: send a test, open Gmail/Outlook, and if it is in Spam mark Not spam. Also set SPF/DKIM/DMARC for your domain in Hostinger DNS.
